# Turnover Dashboard

Explainable employee turnover-risk dashboard with department-level insights.

## Features

- Risk score from 0 to 100.
- Low, medium and high risk classification.
- Web dashboard and documented API.

## Tech Stack

Python, FastAPI, SQLAlchemy, PostgreSQL, React and Recharts.

## Getting Started

```bash
git clone https://github.com/lucaspwalter/turnover-dashboard.git
cd turnover-dashboard
docker compose up
```

Dashboard: `http://localhost:3000`. API: `http://localhost:8000/docs`.
