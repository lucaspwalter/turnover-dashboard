# Painel de rotatividade

Painel de risco de rotatividade com pontuação explicável por departamento.

## Características

- Pontuação de risco de 0 a 100.
- Classificação baixa, média e alta.
- Dashboard web e API documentada.

## Pilha de tecnologia

Python, FastAPI, SQLAlchemy, PostgreSQL, React e Recharts.

## Começando

```bash
git clone https://github.com/lucaspwalter/turnover-dashboard.git
cd turnover-dashboard
docker compose up
```

Dashboard: `http://localhost:3000`. API: `http://localhost:8000/docs`.
